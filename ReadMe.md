[Repository](https://github.com/Rustam-Shrestha/el-proyecto-de-anos-final)

Major project. Multi-tenant PERN and TypeScript loan platform with an ML credit-risk service built on FastAPI. The XGBoost model is trained on 300,000+ Home Credit records and serves real-time risk scores with SHAP explanations.

- Accuracy 85.01%, precision 24.69%, recall 41.75%, specificity 88.81%, F1 30.93%
- AUC-ROC 0.7630 (5-fold cross-validation, fold std 0.0045)
